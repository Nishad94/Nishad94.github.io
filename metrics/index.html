ABOUT THIS PAGE

This public page is generated from the same privacy-safe snapshot used by the Mac dashboard. It publishes aggregate service state and latency only—never messages, email subjects, song history, identities, IP addresses, credentials, filenames, or private host data.

GitHub Pages is a static host, so the snapshot updates when the repository sync workflow publishes a new data file. The local dashboard at 127.0.0.1:8090 remains the real-time source.

Latency is measured from OpenClaw automation start through provider-acknowledged WhatsApp send when available.
