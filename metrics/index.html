ABOUT THIS PAGE

This page is generated from the Mac dashboard’s privacy-safe snapshot. Charts show aggregate utilization and service telemetry only—never messages, email subjects, listening history, identities, IP addresses, credentials, filenames, or private host data.

GitHub Pages is static, so charts refresh when a new snapshot is published. The local dashboard remains the real-time source.

Latency is measured from automation start through provider-acknowledged WhatsApp send when available. Historical points are downsampled to protect privacy and page weight.
